# Cat Management System (MEAN Stack)

A full-stack web application for managing cat records, built using the MEAN stack (MongoDB, Express.js, Angular, Node.js) with TypeScript.

## Features

- **Authentication & Authorization:** JWT-based login and registration with hashed passwords (`bcrypt`).
- **Role-Based Access Control (RBAC):** Admin and User roles with protected routes using Angular Guards.
- **CRUD Operations:** Complete management system to add, view, update, and delete cat profiles.
- **RESTful API:** Clean backend structure with controllers and models.

## Tech Stack

- **Frontend:** Angular, TypeScript, HTML/CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB Atlas
- **Security:** JSON Web Tokens (JWT), Bcrypt
